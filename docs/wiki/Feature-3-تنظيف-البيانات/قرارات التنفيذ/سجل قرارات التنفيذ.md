# سجل قرارات التنفيذ — Feature 3: تنظيف البيانات

تُضاف هنا قرارات التنفيذ عند اتخاذها وفق قواعد صفحة [الغرض وقواعد التوثيق](الغرض وقواعد التوثيق.md).

### IMPL-001: دمج فحص المدخلات وربط الحقول وتصحيح ترقيم المراحل

- **المنفذ/صاحب القرار:** القرار: المستخدم؛ التوثيق: Codex.
- **التاريخ:** 2026-11-25
- **السياق:** احتاج تصنيف الحقول المطلوبة إلى mapping مفاتيح scraping إلى أسماء الحقول المعيارية؛ كما أدى دمج المرحلتين 2 و3 إلى ضرورة تحديث ترقيم المراحل ومعرّفات متطلباتها ومخطط التدفق.
- **القرار والإجراء المنفذ:** دُمج mapping المفاهيمي وفحص JSON والتحقق من الحقول وتصنيفها في المرحلة 2. حُدّثت المراحل التالية ومعرّفات متطلباتها ومخطط التدفق لتتسلسل من 1 إلى 6. بقيت مرحلة mapping بلا database lookups أو FK mapping، وبقي حد `raw_payload` البالغ 5 MB.
- **البدائل المستبعدة وأسباب الاستبعاد:** إبقاء mapping والتصنيف في مرحلتين منفصلتين رُفض لأن فحص الحقول المطلوبة يعتمد على معرفة مقابلاتها المعيارية أولاً.
- **الأثر والمتابعة:** أصبحت وثيقة المتطلبات متسقة مع ترتيب الاعتماد بين mapping والتصنيف. تبقى تفاصيل mapping contract وشكل JSON الدقيقة ضمن التخطيط.

لا تُسجل هنا قرارات التصميم المعماري؛ مكانها ADR.
